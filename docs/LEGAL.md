# Legal notes

This repository contains original code and reverse-engineering notes only.
It does not contain, and must never contain, any Gameloft or Marvel assets:
no packs, meshes, textures, audio, video, text tables or binaries. All of
those are gitignored. Running the port requires the user's own legally
obtained copy of the game.

Format documentation describes structure (offsets, tables, naming
conventions) so the user's own files can be read; it reproduces no content.
