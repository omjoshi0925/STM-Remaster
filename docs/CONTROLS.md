# Controls (current)

Left half drag: move, relative to the camera. Right half drag: orbit the
camera. Punch button (W-266, 511 in 768 pt space, radius 82): attack, mash
to chain. Web button: web attack when web power allows. Dodge button:
reserved. Pause bubble (top left 44 pt): pause and mute. Tap anywhere on
video, title, death and completion screens advances.

Original scheme for reference: fixed joystick bottom left, punch, dodge and
web buttons bottom right, pause top left. Jump, wall crawl and web swing are
not implemented yet.
